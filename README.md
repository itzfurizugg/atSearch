# atsearch

A minimal ambient clock web app — a clean, distraction-free full-screen clock for your browser tab or homepage.

🔗 Live: [ambience-home.vercel.app](https://ambience-home.vercel.app/)

## About

atsearch is a simple ambient clock experience built to sit quietly in a browser tab — no clutter, no distractions, just time. It's designed as a calm homepage/new-tab replacement.

## Features

- 🕒 Full-screen ambient clock display
- 🚀 Dock with customizable shortcut links *(in progress)*
- ☁️ Deployed on Vercel

## Tech Stack

- React + Vite + TypeScript
- Tailwind CSS
- Deployed on [Vercel](https://vercel.com)
